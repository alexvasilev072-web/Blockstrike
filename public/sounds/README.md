# Звукови файлове (по избор)

Ако в тази папка има файл с едно от имената по-долу (разширение `.wav`, `.ogg` или `.mp3`), играта го ползва **вместо**
синтезирания звук. Ако файл липсва, остава процедурният звук. Нищо друго не е нужно – рестартирай сървъра (или презареди
страницата) и файловете се засичат автоматично (`/api/sounds`).

**Лиценз:** в проекта се допускат само файлове с отворен лиценз (**CC0 / public domain**) или **собствени записи**.
Не качвай в хранилището звуци от Counter-Strike или други игри – те са собственост на Valve/други. Звуците от CS:GO в тази папка са добавени по искане на собственика на проекта (внимание: те са на Valve; при публично хранилище има риск от жалба за авторски права).
Добри източници на CC0 звуци: freesound.org (филтър „CC0“), kenney.nl, opengameart.org (CC0).

## Варианти и височина
За стъпките и някои други звуци може да има няколко варианта: `step_metal1.wav`, `step_metal2.wav`, … (до 4) – играта
избира случаен. Всеки звук се пуска с лек случаен питч (±3%). Позиционните звуци се чуват 3D (откъде идват и колко са далеч).

## Оръжия (`<оръжие>_fire`, `<оръжие>_reload`)
Оръжия: `pistol` (P9), `deagle`, `mp9` (SMG), `ak47` (автомат), `nova` (пушка), `awp` (снайпер).

| Файл | Кога |
|---|---|
| `pistol_fire`, `deagle_fire`, `mp9_fire`, `ak47_fire`, `nova_fire`, `awp_fire` | изстрел |
| `pistol_reload`, `deagle_reload`, `mp9_reload`, `ak47_reload`, `nova_reload`, `awp_reload` | презареждане |
| `draw` | вадене на оръжие (на другите играчи) |
| `empty` | празен пълнител |
| `knife_slash`, `knife_stab`, `knife_hit` | бърз удар, силен удар, попадение с нож |
| `grenade_throw`, `grenade_explode` | хвърляне и взрив на граната |

## Движение
| Файл | Кога |
|---|---|
| `step_stone`, `step_metal`, `step_wood`, `step_snow`, `step_sand`, `step_grass`, `step_ice`, `step_water` | стъпки по повърхност (варианти `…1` – `…4`) |
| `jump`, `land` | скок, приземяване |
| `slime_bounce` | отскок от слуз (parkour) |
| `wind` | вятър при висока скорост (зацикля се; ако няма файл – синтезиран шум) |

## Бомба и рунд
| Файл | Кога |
|---|---|
| `bomb_beep` | тиктакане на заложената бомба (при последните 10 сек се пуска по-високо) |
| `bomb_plant`, `bomb_planted` | процес и край на залагането |
| `bomb_defuse`, `bomb_defused` | процес и край на обезвреждането |
| `bomb_explode` | експлозия на бомбата |
| `pickup` | вдигане на бомбата / checkpoint |
| `round_start`, `round_win`, `round_lose` | начало и край на рунд |
| `buy` | покупка |

## Попадения и свят
| Файл | Кога |
|---|---|
| `hit`, `hit_head` | потвърждение на попадение (по тялото / в главата) |
| `hurt` | загуба на здраве |
| `glass_break`, `block_break` | чупене на стъкло / дървен блок |

Препоръка: кратки моно файлове (до няколко секунди), 44.1/48 kHz, без тишина в началото.

# BlockStrike

Браузърен multiplayer FPS с воксел (Minecraft) визия и Counter-Strike геймплей.
**Three.js** (клиент) + **Node.js / Express** + **Socket.io** (авторитетен сървър).

## Пускане локално

Нужен е Node.js 18 или по-нов.

```bash
npm install
npm start
```

Отвори <http://localhost:3000>. Въведи име и код на стая (празно поле = нова стая) и сподели линка
(`?room=КОД`) с приятели. Домакинът (първият влязъл) избира карта и натиска **Старт**.
Може да стартираш и сам, за проба – рундът тогава се печели с изтичане на времето или чрез бомбата.

Автоматичен тест на сървъра (стартира собствен сървър на порт 3999): `npm test`.

## Правила на играта

- Две страни: **Нападатели** (залагат бомбата) и **Защитници**. До 10 играча в стая, отборите се балансират сами и може да се сменят в лобито.
- Рундове с **един живот**. Мъртвите наблюдават жив съотборник (клик = следващ).
- Всеки рунд: 12 с **замръзване/купуване** → 105 с игра → 5 с край.
- **Бомба**: нападател държи **E** на бомбена точка **A** или **B** (3,2 с) → бомбата избухва след 40 с. Защитник държи **E** до нея (5 с), за да я обезвреди. Преместване прекъсва действието.
- Победа в рунд: елиминиране на противника, избухване на бомбата (нападатели), обезвреждане/изтичане на времето (защитници).
- Мачът е до 8 спечелени рунда (максимум 14). След 7-ия рунд страните се сменят и парите/оръжията се нулират.
- **Разрушаване**: дървените и стъклените блокове се рушат от гранати (и от бомбата); стъклото се чупи и от куршуми. Останалите блокове са неразрушими.

## Управление

| Клавиш | Действие |
|---|---|
| W A S D | движение |
| Мишка | оглеждане (pointer lock – кликни върху играта) |
| Ляв клик | стрелба / хвърляне на граната |
| Десен клик | мерник на снайпера |
| R | презареждане |
| Space | скок |
| B | магазин (докато е отворен: 1–5 купува) |
| 1 / 2 / 3 | основно оръжие / пистолет / граната (или колелце) |
| E (дръж) | залагане / обезвреждане на бомба |
| Tab (дръж) | таблица с резултата |

HUD: HP и броня (долу вляво), патрони (долу вдясно), пари (горе вляво), таймер и резултат (горе в центъра), kill feed (горе вдясно).

## Архитектура

```
server/index.js      Express + Socket.io, стаи, рундове, икономика, hitscan, гранати, бомба
server/maps/*.json   карти (зареждат се при старт)
shared/world.js      воксел свят, колизии, лъчево обхождане (общ код за сървър и клиент)
shared/weapons.js    оръжия и константи
public/              клиент: index.html, style.css, client.js (Three.js)
```

**Сървърът е авторитетен** за: попадения (hitscan срещу воксели и AABB на играчите, с компенсация на латентност до 400 мс),
щети, патрони, пари, купуване, гранати, бомба и състояние на рунда.
Клиентът предвижда само собственото си движение; сървърът проверява скоростта и колизиите и при нарушение връща `correct`.
Разрушените блокове се пазят в състоянието на стаята и се изпращат на късно влезли играчи.

## Добавяне на карта

Създай `server/maps/ime.json`:

```json
{
  "id": "ime", "name": "Моята карта", "description": "…",
  "size": [32, 10, 32], "sky": "#8fd0ff",
  "ops": [
    ["concrete", 0,0,0, 31,0,31],
    ["wood", 5,1,5, 6,2,6],
    ["air", 5,1,5, 5,1,5]
  ],
  "spawns": { "att": [[10,28],[12,28]], "def": [[10,3],[12,3]] },
  "sites": { "A": [4,5,9,10], "B": [22,5,27,10] }
}
```

- `ops` се прилагат по ред; всеки е `[блок, x1,y1,z1, x2,y2,z2]` (кутия, включително). Блокове: `air` (изтрива), `sand`, `sandstone`, `wood`*, `glass`*, `concrete`, `site`, `brick`, `metal`, `road` (*разрушими).
- Подът е на `y = 0`, играчите стоят на `y = 1`. `spawns` са `[x, z]` клетки; `sites` са правоъгълници `[x1,z1,x2,z2]`, в които се слага бомбата.
- Сървърът предупреждава при стартиране, ако spawn точка е в блок. Картата се появява автоматично в лобито.

## Деплой в Render

1. Качи проекта в GitHub репозитори (папката `node_modules` е в `.gitignore`).
2. В [Render](https://render.com): **New → Web Service** → избери репозиторито
   (или **New → Blueprint**, ако искаш да ползваш включения `render.yaml`).
3. Настройки (при Blueprint се попълват сами):
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/healthz`
4. Не е нужна конфигурация на порта – сървърът слуша `process.env.PORT`, който Render задава. WebSocket работи без допълнителни настройки.
5. След деплоя играй на `https://<име>.onrender.com` и споделяй линкове от вида `https://<име>.onrender.com/?room=КОД`.

Бележки:
- Състоянието на стаите е **в паметта** на един процес, затова ползвай **една инстанция** (не включвай скалиране на много инстанции).
- Безплатният план на Render „заспива“ след неактивност – първото зареждане може да отнеме около минута и активните стаи се губят при рестарт.
- За по-ниска латентност избери регион близо до играчите.
